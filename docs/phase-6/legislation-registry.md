# Phase 6 legislation registry

Official-source metadata is held in tax/catalogue.py. Engagement-owned tax-rule records carry source ID, article, decision, effective interval, legal knowledge date, document version/hash, conditions, exceptions, typed parameters, technical-review rationale and lifecycle. Their revisions and independent review decisions persist. Approved legal records cannot reopen: amendments require a new rule/version. Technical review is required before a profile can reference a rule; catalogue metadata is never automatically approved. Document hashes are optional and must be supplied when an exact acquired document is retained; this registry is not a full-text legal archive.
