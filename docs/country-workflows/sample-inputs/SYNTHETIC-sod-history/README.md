# Synthetic UAE and India access history

Each country folder saves an access CSV, fictional policy, independent-count memo
and expected outcomes/checksums. These are authored test cases, not client files
or independently approved real client expectations. Upload each source as a
separate evidence record, independently approve it, then use the resulting
approved record IDs in the policy and CSV import. IDs are engagement-specific;
never reuse a file-version ID where an approved record ID is required.

Use the exact policy for the first two cases. For the reviewed-overlap cases,
explicitly add A/B, rationale and Appendix 2 to the approved policy. The policy
covers all of calendar 2026. History analysis needs the separate counts memo,
its reference and an explicit source scope/coverage assessment. All dates are
inclusive. Only the historical reviewed-overlap case detects the revoked
create/approve combination from January through June. A December snapshot
does not establish historical completeness.

No application role expansion, wildcard/global scope, transitive scope
hierarchy, timestamp/timezone interpretation, ERP-native extraction, source
completeness or SOX/IFC/country applicability is inferred. Results are candidates
for professional assessment. Real pilot folders remain under `pilot-data/`.
