SYNTHETIC UAE VAT201 e-commerce split examples

These are authored engine fixtures, not client returns or independently approved
legal schedules. Import each CSV as a separate return-boxes source, with AED tax
control 230 and row count 20. The all-box taxable amount is 2400 and adjustment
control is 0; these include summary rows and are not tax payable.

Select ecommerce-20 for comparison. Each Box 1a-1g has six explicit columns:
ecommerce_taxable_amount, ecommerce_tax, ecommerce_adjustment,
other_standard_taxable_amount, other_standard_tax, other_standard_adjustment.
Zero means assessed nil, not omitted evidence. Leave these columns empty outside
Box 1a-1g. Each pair must sum to the corresponding emirate total in all three
amount columns. Both categories are compared separately between books and return.

The examples place all supplies in the e-commerce component for arithmetic
testing only. They do not establish qualifying-registrant status, reporting
duration, goods/services receipt location, group scope or legal eligibility.
Retain and independently review original supporting evidence for those facts.
The comparison and report remain unsigned working drafts, with no portal filing.
