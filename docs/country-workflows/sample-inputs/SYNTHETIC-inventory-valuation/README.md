# Synthetic inventory valuation examples

Use AE first, then IN. All figures and supporting text are fictional. These
files are reproducible demonstrations, not client pilots or independently
certified expected results.

Upload each CSV and the separate cost/NRV text documents as retained evidence.
Prepare books as `stock`, valuations as `inventory-valuations`, and controls
as `accounting-controls`. Copy the independent controls from
`scope-controls.json`. For valuations select the uploaded cost and NRV document
versions: the blank CSV document IDs and hashes are then filled from those
retained documents. Independently review all three prepared sources.

Run `inventory-valuation-control` with the stated dates, explicit recorded GL
basis and a meaningful framework/cost-policy assessment. This fixture expects
one valuation test and one GL control, with zero exceptions. Production review
must assess evidence, quantities, ownership, cost policy and applicable
reporting framework independently.
