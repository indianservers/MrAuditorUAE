# Visual reference audit

All ten originals were opened individually before implementation. Actual Chromium screenshots are saved at 1672×941 and at each PNG's exact native dimensions. This is a structural visual comparison, not a claim of pixel equivalence: reference customer data is fictional, some screenshots are collage fragments, and future-phase services cannot be represented as completed work.

The final screenshots use labeled synthetic records returned by the real backend. No target image, crop or screenshot is a product background. The shared shell follows the high-resolution references 04/06/07: 195px navigation, 56px header, compact blue selection, white surfaces and cool-gray borders. A persisted dark-sidebar preference preserves the alternate reference style.

## Corrections after browser comparison

The first capture exposed lifecycle badges inheriting the circle selector, overly wide trial-balance columns, scientific-zero amounts shown as unavailable, cramped risk-score decimals, chart-header overlap and low-contrast secondary text. These were corrected. A local Inter variable font replaced the initial Arial fallback; selection moved to a narrow pinned first column; chart units and source labels were clarified. Final screenshots exclude the Next development indicator and wait for authorized query results.

## Responsive and accessibility scope

Body overflow bounds were verified at 1920×1080, 1600×900, 1440×900, 1366×768, 768×1024 and 390×844 on the compliance layout; native reference captures also exercise narrower versions of all ten layouts. Financial tables retain readable widths with internal horizontal scrolling. The navigation collapses on narrow screens; source drawers become full width. Reference-sized collage captures are responsive application views, not reconstructions of the surrounding collage.

`visual-measurements.json` contains viewport/body/row measurements. `accessibility.json` records the automated axe results for the compliance route. Keyboard tests cover command palette, Escape dismissal, navigation and financial drill-down. This is not full cross-browser or assistive-technology certification. No unsupported visual-match percentage is claimed.
