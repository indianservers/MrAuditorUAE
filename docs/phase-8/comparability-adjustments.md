# Comparability Adjustments

Screening supports documented PLI-point financial adjustments. Each nonzero adjustment requires an evidence basis. Working-capital adjustment is explicit: the tested net working-capital/revenue ratio less the comparable ratio, multiplied by a reviewed financing rate. The result applies only when selected, with source and methodological support.

The tool does not automatically normalize accounting standards, infer risk premia, make geographic adjustments or resolve functional incomparability. Weighted financial pooling does not accept PLI-point adjustments because its denominator treatment would be ambiguous. Source financial adjustments must be established in a reviewed dataset version first.
