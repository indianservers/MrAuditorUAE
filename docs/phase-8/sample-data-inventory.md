# Sample Data Inventory

The guarded enrichment script requires development/test mode, SYNTHETIC_DATA_ENABLED, the exact dedicated demo database and expected tenant identity, plus the existing noncommitted demo password. It never truncates or replaces Phase 7 sources. Stable references, upload hashes and immutable dataset versions make replay reuse the existing records.

The Phase 8 manifest records 100 transactions, 20 approved loan fixtures, ten approved service allocations, ten incomplete remuneration cases, five studies, 5,020 observations, eleven parties, ten relationships, three draft Local Files and one draft Master File. Six additional TP demo roles have isolated memberships and engagement grants. The prior ten clients, ten entities, thirty engagements and 250,024 source journal lines remain present.

All companies/observations are synthetic. A fictional RP classification overlay is not a claim about the original source business. Draft remuneration and document gaps are intentional visible limitations. See demo-manifest.json, demo-seed-log.txt and demo-replay-log.txt; secrets are stored only in ignored local runtime files.
