# Service Cost Allocation

A service workpaper links an actual source cost pool, controlled transactions, provider, recipient parties, allocation driver, methodology, benefit test and selected markup. Source cost amounts must reconcile exactly. Allocation recipient IDs must match the reviewed beneficiary population. The engine computes allocated cost, markup, charge and allocation difference using Decimal arithmetic.

The simplified approach is an explicit reviewed fact, not an automatic 5% default. The markup is user-selected; the application does not declare it market supported. The demo includes ten source-reconciled synthetic allocations. Shareholder costs, duplication, commercial benefit and pass-through treatment require professional assessment; an allocation total alone does not prove deductibility.
