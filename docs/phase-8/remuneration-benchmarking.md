# Remuneration Benchmarking

Remuneration combines base pay, bonus, allowances, benefits and management fees. It compares the result to selected actual GL-backed controlled transaction amounts and exposes any difference. Calculation requires those transactions to reference the same connected person through an approved CONNECTED relationship.

Responsibilities, commitment, experience, company size/performance and comparability adjustments are explicit evidence-backed assessments. An optional study must be an AED remuneration population. A percentile does not establish excessive pay, commercial benefit or deductibility. The tested workflow reconciles AED800,000 compensation and creates a separately reviewed upward CT adjustment draft.

The ten demo remuneration cases remain IN_PROGRESS: existing source purchases are not payroll, so they cannot be represented as completed director-pay reviews. Commercial remuneration data, payroll and actual connected-person evidence remain prerequisites for real conclusions.
