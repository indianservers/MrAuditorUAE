# Transaction Classification

The controlled matrix uses independently approved transaction workpapers pointing to actual active journal lines in the engagement entity and period. Posting date, native/functional currencies, FX and both signed amounts must match the ledger. One economic leg per journal prevents recording both debit and credit as two controlled transactions. Economic keys and journal legs cannot be classified twice, including across draft records.

Original entries, settlements and eliminations are distinct. Dividends are separately categorized; reversal treatment is an explicit reviewed fact. Income and expense are not netted against each other for disclosure thresholds. Classification requires an approved effective RELATED or CONNECTED relationship and counterparty membership in that relationship.

The candidate endpoint provides exact-name and keyword evidence for human review. It does not infer a legally related party from a name or automatically populate the approved matrix. The demo overlays 100 explicitly synthetic affiliate classifications on preserved Phase 7 source entries. That fictional overlay is not evidence about any real business.
