# Ai Tp Assistant

Thirty TP tasks are registered, spanning relationship candidates, contracts, FAR, methods, screening, benchmarks, segment results, loans, services, remuneration, DEMPE, documents, disclosures and reviewer queries. The gateway uses the approved TP profile, scoped source, optional immutable deterministic run, legal citations and period context. Context is bounded and tenant hourly budget enforced.

Licensed data requires AI-disclosure permission and unexpired authorization. External model use requires configured approved provider/model and disclosure authorization. The diagnostic mock supports deterministic CI checks; it is not an economist or production legal model. AI cannot establish verified comparables, approve arm’s length conclusions or write computed financial amounts into source books.

Suggestions persist with execution/prompt/source lineage and SUGGESTED status. Independent acceptance rechecks reviewer separation, sources, legal versions, licensing and run freshness. Legacy AI entry points reject TP sources. Tests execute all thirty diagnostic task routes and budget/separation restrictions. Production economic quality, adversarial robustness across real model providers and professional acceptance evaluations remain outstanding.
