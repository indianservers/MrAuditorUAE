Working tested paths include refresh-token reuse protection, tenant isolation, real accounting import/normalization/source lineage, GL/TB, analytics/sampling, engagement grants, independent review chains, evidence quarantine, restricted portal, IFRS specialist calculations/consolidation and scoped Corporate Tax. The existing test inventories contain numerical fixtures, not evidence of universal accounting/legal coverage.

Partial/missing: no VAT profile, VAT invoice facts, VAT201 mapping/reconciliation or structured e-invoice/ASP adapter exists. Taxpayer special cases, complex CT group attributes, cross-engagement IFRS sourcing and live AI semantic accuracy remain limited as documented in Phase6. Older preview seed scripts use DEMO_SEED alone, hardcoded integration credentials and non-idempotent fixture creation; they are not suitable for the required demo environment. The integration fixture truncates a database without checking its actual identity: a high-severity test-runner safety defect to repair before new seeding. Existing AI output is source/schema bounded, with diagnostic mock rather than verified legal research.

UI: all20 Phase6 routes had prior browser evidence, but this is not a fresh application-wide UI audit. Some complex schedules use JSON editors. Legacy Compliance/Tax/supporting controls and route actions require fresh browser/action inventory; missing controls will not be called working solely because a route renders. Existing financial lists are paginated; large-demo import/query/render performance is not yet measured. Full-system screenshots, role/browser checks, defect fixes and measurements will be recorded separately during Phase7.

Architecture plan: retain existing financial sources and AuditRecord/revision/review infrastructure; add VAT-specific strict schemas and permissions, immutable VAT runs/ASP sandbox events, approved date-aware rule versions, actual invoice-to-ledger reconciliation and a guarded versioned demo dataset manifest. Use a dedicated local demo database and tenant; production and identity mismatches must fail before mutation. No Phase8–12 work is authorized.
