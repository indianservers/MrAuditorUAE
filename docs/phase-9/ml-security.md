# Ml Security

Every API rechecks tenant, active membership, role and engagement scope. Trainer self-approval is denied. Private object keys are generated by the server and artifacts are hash checked. No uploaded JavaScript/model execution or confidential cross-tenant pooling is supported. Curation requires a different authorized reviewer and preserves evaluation splits. Owner-scoped cancellation kills the real child. RLS and immutable UPDATE rejection are tested. Generic AI routes cannot bypass DMTT source controls. Production penetration testing is not claimed. Three moderate transitive npm advisories remain documented in npm-audit.json.
