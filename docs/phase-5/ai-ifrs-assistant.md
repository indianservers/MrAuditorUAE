# IFRS technical assistance

The IFRS router reuses configured providers, execution/usage history and versioned prompts. Structured outputs require source UUID citations, missing information, human-review and explicit no-opinion/no-sufficiency flags. Unknown citations fail execution. Retrieved sources are bounded, allowlisted, untrusted data. No licensed IFRS text is supplied; prompts forbid authoritative paragraph claims.

All 20 tasks are enumerated and exercised through the diagnostic provider. Diagnostic output verifies workflow/schema/source linkage; it is not professional semantic analysis. External disclosure requires approved provider/deployment configuration. Suggestions remain REVIEW_REQUIRED until an independent reviewer records a decision. They cannot mutate figures, approve assumptions or certify disclosure completeness.

The service retains tenant hourly budgets, context bounds and model/prompt/execution IDs. It reuses AuditAIOutput, including proposed-procedure fields, rather than claiming a complete IFRS expert schema. The UI selects note sources; the API also accepts other authorized Phase4 sources.
