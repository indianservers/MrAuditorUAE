# Controlled adjustment overlay

Each journal leg has exactly one positive debit or credit. Journals balance exactly, use imported chart accounts, match entity currency and fall within the reporting period. Only approved/locked journals affect the overlay. Original ledgers remain immutable. Reversals must exactly reverse an approved journal; disclosure-only records cannot post balances.

The proposal endpoint derives initial lease liability or ECL allowance movement from a current immutable run. ECL movement subtracts an explicitly entered existing allowance. Human-selected accounts and independent approval are required. Other journals may be manually prepared with supporting run linkage; linkage alone does not certify numerical agreement, so reviewers must inspect the journal.

Changed supporting assumptions prevent applying their journal and invalidate dependent reports. Current-period overlays reject consolidation and prior-period journal types. Group eliminations use the consolidation workbench. Separate comparative profiles support prior reporting; a fully automated IAS 8 restatement workflow is not implemented.
