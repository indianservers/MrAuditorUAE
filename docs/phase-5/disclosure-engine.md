# Original disclosure aid and notes

Approved categories cover presentation, policies, judgments, subsequent events, going concern and every populated note reference. Applicable responses require linked approved notes; unknown responses cannot complete the gate. Not-applicable responses require rationale. IFRS18 applicable responses require an effective period or early election; IFRS19 requires an eligible elected profile.

This original category aid is not a comprehensive authoritative checklist. Eligibility does not certify reduced-disclosure completeness. Notes contain controlled narrative, mapped line codes, calculation IDs and an AI-authored flag. Numeric tables copy report values; stale supporting schedules block generation. Narrative completeness and professional judgments remain human responsibilities.
