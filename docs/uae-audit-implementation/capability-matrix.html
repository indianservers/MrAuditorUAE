Scoped core means a dedicated bounded workflow exists; partial means material engineering/qualification remains; evidence only means generic workpapers/checklists. No category means full legal or production readiness.

What works without external AI credentials

  • Deterministic calculations/reconciliations, source-linked evidence, independent review, exports and the new audit workflows.
  • Explicit rules/statistical baselines. Explicit diagnostic mode produces a diagnostic result and no model score.
  • TensorFlow.js CPU inference when an approved compatible private artifact exists. Synthetic real fitting/inference was tested; no real-client quality or production promotion is claimed.

A configured OpenAI-compatible gateway is needed only for optional language-model explanations/drafts. Diagnostic gateway responses are labelled. Account suggestions never determine VAT treatment or tax deductibility.
