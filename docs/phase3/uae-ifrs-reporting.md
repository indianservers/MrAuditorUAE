# UAE IFRS reporting

Reused: existing IFRS mapping, calculation, disclosure and export modules, accounting snapshots and source lineage. The country dashboard links the existing IFRS workspace. This phase adds reviewed source-backed statutory report blocks and immutable report/template receipts. IFRS calculation blocks require an approved audit release record tied to the calculation ID, current underlying dependencies and IFRS permission.

Historical approved calculation runs are preserved. Report generation does not sign an opinion or file statements. Independent accounting validation remains necessary for the entity's framework, disclosures, accounting judgements and complete statement presentation. The concurrent financial-review workspace is preserved; its delivery evidence is maintained under `docs/financial-reporting`.
