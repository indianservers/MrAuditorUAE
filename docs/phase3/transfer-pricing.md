# Transfer pricing

Reused the existing related-party, transfer-pricing calculation and benchmarking modules, source observations and working papers. New report categories include local and master files. A TP calculation block requires the approved audit release record, exact calculation run, module permission and current dependency hashes; a report cannot convert an unreviewed run into an approved conclusion.

The country dashboard exposes the existing TP workspace. Full jurisdiction-specific local/master file content, period thresholds and professional economic analysis still require qualification. Report categories are composition tools, not representations that statutory document content is complete.
