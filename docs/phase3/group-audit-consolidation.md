# Group audit and consolidation

Reused existing group/consolidation engagement workflows, elimination records and source history. Added group-audit component evidence checklists and group/consolidation report categories. Components retain entity-specific approved context; parent source dependencies remain visible in working papers. A stale child or changed applicable rule requires renewed review without overwriting the earlier conclusion.

The report designer composes reviewed group outputs; it does not create missing consolidation adjustments. Completeness of consolidation scope, FX translation, NCI, goodwill, controlled eliminations and component auditor reporting must be assessed in the existing engine and professionally reviewed. This phase does not claim new qualification of every consolidation scenario.
